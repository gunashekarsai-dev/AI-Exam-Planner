# Quick Start Guide - AI Exam Revision Planner (Premium UI)

## 🚀 Getting Started in 30 Seconds

### 1. Start Development Server
```bash
cd frontend
npm run dev
```
Then open **http://localhost:5173** in your browser.

### 2. See the App
✨ **Landing Page** → Click "Create my plan" → **Onboarding** (4 steps) → Click "Generate" → **Processing Screen** → **Dashboard**

---

## 📋 What You'll Experience

### Landing Page
- Beautiful hero section: "Plan smarter. Revise better."
- 3D animated AI core with floating metric cards
- CTA button to start planning
- Premium glassmorphic design

### Onboarding (4 Steps)
1. **Student Info** - Name, course
2. **Exam Details** - Date, subjects
3. **Topics** - Chapters to cover, weak areas
4. **Preferences** - Study hours, preferred time

Each step shows progress and has helpful guidance.

### Processing Screen
Animated screen while "AI builds your plan":
- Rotating rings visualization
- Sequential processing stages
- Status indicators (✓, ⏳, ○)

### Dashboard
Complete study hub with:
- Exam countdown
- Progress metrics (72%)
- Subject tracking (Math, Physics, CS)
- Today's schedule
- AI coaching recommendations
- Streak motivation (🔥)

## ❓ FAQ

**Q: How do I change the name/course?**
A: Fill in on Step 1 of onboarding. Name appears on dashboard.

**Q: What's the processing screen?**
A: Beautiful animation showing plan generation. Transitions to dashboard after ~4 seconds.

**Q: Can I go back?**
A: Yes! Click "← Back" in onboarding, or "Home" in nav to restart.

**Q: How do I make a new plan?**
A: Click "+ New plan" button on dashboard, or "Home" in nav.

**Q: Is this connected to a backend?**
A: Currently frontend-only (mockup). Ready to integrate with Django backend.
